# 도자 옻칠 수리 B5 실습편: v9 → v11 변경점

비교 대상
- v9: 「도자기 옻칠 수리 - 실습 교정본 v9」 (downloadfile-16-1.pdf, 10쪽, 약 1MB)
- v11: 「도자 옻칠 수리 · 접합에서 킨츠기까지 (B5 실습 1~12단계)」 (10쪽, 약 22MB)

두 판 모두 B5(515.9 × 728.5pt) 10쪽이다.

## 1. 전체에 걸친 변경

| 항목 | v9 | v11 |
|---|---|---|
| 제목 | 도자기 옻칠 수리 / 접합에서 **마감**까지 | 도자 옻칠 수리 / 접합에서 **킨츠기**까지 |
| 머리글·바닥글 | "B5 실습・1~12단계 / 마감 참고"가 쪽마다 두 번씩 중복 | 머리글 "B5 실습 · 1~12단계", 바닥글 "도자 옻칠 수리 NN/10"으로 정리 |
| 쪽 번호 | 01/08, 05/08 등 총 쪽수가 섞여 있음 | 전부 NN/10으로 통일 |
| 교정용 문구 | "기술 검토용", "실제 촬영/생성 도판은 별도로 구분", "편집 교정본" 등이 남아 있음 | 모두 삭제 |
| 이미지 캡션 표기 | "설명용 재구성 · 실물 작업 사진 아님", "승인된 설명용 사진", "설명용 생성", "제공된 실제" 등 제각각 | 예시 이미지는 "이해를 돕기 위한 예시 이미지"로 통일, 실제 작업 사진은 "박미란 작업"으로 표기 |
| 이미지 해상도 | 대부분 약 135dpi (JPEG) | 226~354dpi (대부분 무손실) |
| 글꼴 | - | Noto Sans CJK KR / Noto Serif CJK KR 내장 |

## 2. 쪽별 내용 변경

| 쪽 | 변경 내용 |
|---|---|
| 01 | **"실습 전 안전" 상자 신설**: 니트릴 장갑·팔토시·앞치마 착용, 묻었을 때 기름으로 먼저 닦고 비누와 물로 씻기, 생옻이 닿으면 옻오름(가려움·붉어짐·물집)이 생길 수 있음, 완전히 굳은 옻칠에는 옻이 오르지 않음 |
| 02 | 호칠을 섞는 도구가 **금속 헤라 → 나무 헤라**로 바뀜("나무 헤라의 넓은 면으로 섞는다"). 이미지 캡션에 "호칠" 명칭 추가 |
| 03 | 경화 설명이 구체화됨: "계절과 혼합 상태를 고려해 충분히 기다린다" → "**옻은 말라서가 아니라 산화 반응으로 굳는다. 온도 20~25℃, 습도 70~80%의 칠장에서 굳힌다**" |
| 04 | "토분과 생옻으로 만든 토회" → "토회(토분+생옻)"로 간결하게 정리 |
| 05 | 경화 관련 문장 정리: 칠장에서 충분히 굳히고, 각 칠의 경화 상태를 확인하도록 서술 |
| 06 | "중요" 상자(금박은 금을 얇게 편 박이다. 순금분이나 금색 안료와 혼동하지 않는다)의 위치 정리. 사진 출처가 "제공된 실제" → "박미란 작업" |
| 07 | 캡션 표기만 정리("설명용 생성" → "이해를 돕기 위한 예시", "승인한" 삭제) |
| 08~10 | **쪽 순서 재배치** (아래 표) |

## 3. 08~10쪽 순서 재배치

| 쪽 | v9 | v11 |
|---|---|---|
| 08 | 참고: 금분과 은분 (순금분 올리기, 순은분 입자) | **12단계 완성 및 최종 기록** + 금속 마감의 네 가지 방법 |
| 09 | 12단계 완성 및 최종 기록 + 금속 마감의 네 가지 방법 | **수리된 그릇, 다시 마주하는 시간** (말차 연출 장면) |
| 10 | 수리된 그릇, 다시 마주하는 시간 (말차 연출 장면) | **참고: 금분과 은분** |

v11은 본편(1~12단계 → 완성 → 마지막 장면)을 먼저 끝내고, 참고 자료(금분·은분)를 맨 뒤로 보냈다.

재배치와 함께 바뀐 문구
- 완성 기록(v11 08쪽): v9의 한 줄 나열("수리 전·후 사진, 재료명, 작업일, 공정별 경화 상태")이 항목별 설명으로 풀림. 완성 기록 사진 / 재료명 / 작업일 / 경화 상태 / 식기 사용("식기 사용 여부는 기록과 별도로 평가한다").
- 완성 기록에서 **빠진 내용**: v9의 표면 점검 항목(금박 들뜸과 수리선 폭, 주변 유약층의 긁힘, 구조·충전부의 균열·박리 여부, 사용·세척·열 조건 확인)과 "주의 | 외관이 완성됐다는 이유만으로 실제 식기 사용의 안전성을 단정하지 않는다"는 문장이 v11에는 없다.
- 네 가지 방법(v11 08쪽): 은박 설명에 "**처음엔 희게 빛나다가 시간이 지나며 검게 변한다**" 추가.
- 금분·은분(v11 10쪽): 도구 표기에 풀이 추가, "모봉·진면" → "**모봉(털붓)·풀솜(진면, 眞綿)**".

## 4. 확인이 필요한 점

- v9의 표면 점검 항목과 식기 사용 안전성 주의 문구가 v11에서 빠진 것이 의도한 삭제인지 확인이 필요하다. v11 09쪽 끝에는 "실제 사용 여부는 각 기물의 접합 안정성과 재료, 경화 및 안전성 검토 결과를 바탕으로 결정한다"는 문장이 남아 있다.
- v11 이미지는 17장 중 16장이 여전히 300dpi 미만이다. 자세한 수치는 `v11_해상도점검_실측.txt` 참고.
